# Content Writing

Generate long-form written content with consistent voice, structure, and research citation.

## Writing Process

### Phase 1: Brief & Research
- Understand the audience and purpose
- Gather source materials and references
- Identify key message and tone

### Phase 2: Outline
Create a structured outline before writing:

```
## Outline
1. **Title/Headline**
2. **Opening hook** (1-2 sentences)
3. **Context/Background** (paragraph)
4. **Key points** (2-4 sections with subheadings)
5. **Evidence/Examples** (data, citations, case studies)
6. **Conclusion** (summary + call to action)
```

### Phase 3: Draft
Write in the specified tone:
- **Technical**: Precise, data-driven, minimal adjectives
- **Professional**: Formal, structured, evidence-backed
- **Conversational**: Direct, approachable, examples-heavy
- **Persuasive**: Benefit-focused, social proof, urgency

### Phase 4: Review
- Check for consistent terminology and voice
- Verify all claims are supported by the cited sources
- Trim redundant phrases; aim for concise, scannable text
- Check reading level matches target audience

## Citation Format
```
[1] Author, "Title," Publisher, Year. URL
[2] ...
```

## Rationalizations

| Excuse | Rebuttal |
|--------|----------|
| "I'll just write it without an outline" | Outlines catch structural issues before you invest time in prose. |
| "I know the voice well enough" | Tone drifts without explicit guidelines. Document it. |
